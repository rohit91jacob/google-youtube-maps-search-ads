# Data licences and attribution

Every source is real, public and credential-free. Data is downloaded at runtime and never
committed, except the small OpenStreetMap fixtures that ODbL allows to be redistributed. The other
test fixtures are **synthetic** (see below). Terms were checked on 9 October 2026.

| Source | What is used | Terms | Redistribution in this repo |
|---|---|---|---|
| **Google Trends** trending-now RSS, `https://trends.google.com/trending/rss?geo=<GEO>` | Trending searches, approximate search volume bucket, start time, first news item | [Google Terms of Service](https://policies.google.com/terms); no open-data licence is published for the feed | **Not committed.** Tests use synthetic feeds with the same XML shape. The results site shows aggregates and the top three current searches per geo, credited to Google Trends. |
| **Political Advertising on Google** transparency bundle, `https://storage.googleapis.com/political-csv/google-political-ads-transparency-bundle.zip` (the files behind BigQuery's `bigquery-public-data.google_political_ads`) | `advertiser-stats`, `advertiser-weekly-spend`, `advertiser-geo-spend`, `geo-spend`, `updated` (the 2.9 GB creative-level file is not taken) | Published by Google for public transparency ([report](https://adstransparency.google.com/political), [FAQ](https://adstransparency.google.com/political/faq)); no explicit redistribution licence was found | **Not committed.** Tests use a synthetic bundle with the real CSV headers. |
| **Netflix Top 10**, `https://www.netflix.com/tudum/top10/data/{all-weeks-global,all-weeks-countries,most-popular}.xlsx` | Weekly global and per-country Top 10 lists, all-time most-popular lists | [Netflix Terms of Use](https://help.netflix.com/legal/termsofuse); the files are offered for download on [netflix.com/tudum/top10](https://www.netflix.com/tudum/top10) without an open licence | **Not committed.** Tests use synthetic xlsx files with the real columns. |
| **OpenStreetMap** via the [Overpass API](https://overpass-api.de/) | Counts of features tagged `amenity=*` in fixed boxes around 8 city centres | [Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/), © OpenStreetMap contributors ([copyright](https://www.openstreetmap.org/copyright)); Overpass [usage policy](https://dev.overpass-api.de/overpass-doc/en/preface/commons.html) (we send ~8 small count queries a week with an identifying User-Agent) | **Committed:** `tests/fixtures/osm/*.json`, eight unmodified Overpass count responses (about 4 KB each, OSM data of 9 Oct 2026). Redistributed under ODbL with this attribution. |
| **YouTube** channel RSS feeds, `https://www.youtube.com/feeds/videos.xml?channel_id=<ID>` | The 15 latest uploads of 7 official channels (Google, YouTube, Google for Developers, Google Cloud Tech, Google DeepMind, Android Developers, Netflix) with view counts | [YouTube Terms of Service](https://www.youtube.com/t/terms) | **Not committed.** Tests use synthetic feeds. |
| **YouTube Data API v3** (optional, only when `YOUTUBE_API_KEY` is set) | `channels.list` statistics and `playlistItems.list` uploads | [YouTube API Services Terms](https://developers.google.com/youtube/terms/api-services-terms-of-service) | **Not committed.** Tests use synthetic responses in the recorded API shape (`tests/fixtures/synthetic/youtube/api_*.json`). |

## Synthetic fixtures

`tests/fixtures/synthetic/` is generated by `scripts/make_synthetic_fixtures.py` with a fixed seed.
It contains **made-up values** in the exact formats of the sources above (XML namespaces, CSV
headers, xlsx columns, API JSON). Every synthetic name says "synthetic" (for example
`SYNTHETIC COMMITTEE ALPHA`, `Synthetic Film EN 03`, `synthetic us term 07`), and every file
carries a notice. Nothing derived from synthetic fixtures is ever published on the results site;
the site is built only from real downloads by `refresh.yml`.

## What you must do if you publish derived data

* **OpenStreetMap (ODbL):** credit "© OpenStreetMap contributors" and state that the data is
  available under the ODbL. A derived database you make public must also be offered under the
  ODbL. The results site and README do this.
* **Google, Netflix, YouTube:** credit the source. Do not republish their raw files. This project
  publishes only aggregates and short factual excerpts (titles, search terms, advertiser names) with
  attribution.

This project is not affiliated with Google, YouTube, Netflix or the OpenStreetMap Foundation. All
trademarks belong to their owners.
